# XPortal Networks Changelog

**## 2.0.0 - Portal Networks & Valheim 1.0+ Update
* Renamed and expanded into **XPortal Networks**
* Added **Portal Networks** System:
  * **Global / Public Network**: Accessible to all players on the server.
  * **Player Networks & Private Portals**: Personal networks per player with private portal protection.
  * **Custom Named Networks**: Support for up to 15 server-wide custom networks defined in `xportal_networks.json` with live hot-reloading.
* Added Server Admin & Permission Controls:
  * Restrict portal deconstruction/destruction to creator or server admins.
  * Server-enforced synchronized settings.
* Modernization & Bug Fixes:
  * Upgraded for Valheim 1.0+ and .NET Framework 4.8.
  * Updated dependencies to BepInEx 5.4.2350 and Jotunn 2.30.0.
  * Fixed controller legend and gamepad navigation issues.
  * Fixed dedicated server admin portal destruction permissions.
  * Improved ZDO network synchronization and portal connection reliability.**
